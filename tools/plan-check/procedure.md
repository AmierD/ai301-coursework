# Procedure: how this skill grades a plan package

## Read order

1. Read the issue that the plan is for first to understand the problem that the
  author is solving
2. Read the claim comment by the author of the plan in the issue thread
3. Read the reproduction report comment by the author of the plan in the issue
  thread
4. Read the prospective plan comment being graded by this skill.

## Evidence gathering

live mode:
* diagnosis: reproduction report in issue thread by plan author
* scope: proposed changes in plan comment
* approach: proposed changes in plan comment
* test: testing plan in plan comment
* thread-repo-conventions: description of the issue the plan is for, the
  comment thread of the issue, the repo contribution information (usually a 
  CONTRIBUTING.md or similar in the root or docs directory in the repo)
* issue-match: description of the issue and previous reproduction report in
  issue thread by plan author

eval mode: quote relevant lines form the bundle

## Check execution

Grade each check pass, fail, or unclear with a one-line evidence quote or fact
for each grade. Unclear means the evidence needed is genuinely absent, not that
you did not look.


## Verdict assembly

Apply the rubric's verdict rule to produce the final verdict:
accept (ready to post) or reject (hold). There is no third verdict

In live mode, hold the drafts against voice-guide.md and note any broken rule
in the summary.
